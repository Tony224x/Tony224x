### Ce que je construis en public

**[mastering-believe](https://github.com/Tony224x/mastering-believe)** — 12 parcours d'apprentissage
profonds : agents, system design, réseaux de neurones, robotique — mais aussi finance personnelle,
rationalité, communication. Théorie sourcée, code exécutable, exercices gradués avec solutions,
capstone par domaine. La structure est tenue par un outil, pas par la discipline :
`shared/tools/build_catalog.py --check` et `check_links.py` refusent un commit incohérent.

**[agent-base](https://github.com/Tony224x/agent-base)** — template monorepo pour agents
conversationnels : LangGraph, architecture hexagonale, Web Component `<agent-chat>` intégrable dans
n'importe quelle app, contrats JSON Schema partagés front/back, streaming SSE. Les limites du
template sont écrites noir sur blanc dans le README plutôt que découvertes à l'usage.

**[mcp-base](https://github.com/Tony224x/mcp-base)** — base pédagogique MCP : six tutoriels progressifs
du premier serveur aux clients (SDK brut, Claude API, agent ReAct LangChain).

**[skills-for-all](https://github.com/Tony224x/skills-for-all)** — skills partagés : relecture
littéraire de manuscrits et audit UX.
